# Dodi's Neovim Config

Single-file configuration based on [kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim).

Uses [mini.nvim](https://github.com/nvim-mini/mini.nvim) plugins when available to reduce the number of plugins to install.

## Requirements

By default, the config requires the following tools in path: 
- [rg](https://github.com/BurntSushi/ripgrep)
- [fd](https://github.com/sharkdp/fd)

_The configuration can be edited to remove those dependencies if needed but note that it might affect pickers speed._
